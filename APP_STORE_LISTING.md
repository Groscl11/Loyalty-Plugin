**Testing instructions** (≤2800)
```
About the app:
Loyalty Rewards by Goself adds a points-based loyalty program to a store. Customers earn points when they place an order and redeem them for discount codes at checkout.

Merchant setup:
1. Install the app from the test store admin.
2. After install you are redirected to the Goself dashboard and signed in automatically.
3. Open Loyalty Program and set an earning rate (for example, 1 point per 1 currency spent) and a reward (for example, 100 points for 10% off). Save.
4. In the Shopify theme editor, add the "Loyalty Rewards Widget" app block to the storefront and save.

Customer flow:
5. On the storefront, log in as a customer and open the loyalty widget to see the points balance and available rewards.
6. Place a test order and mark it as paid.
7. Within about a minute the order awards points. Refresh the widget to see the updated balance.
8. Redeem a reward from the widget to generate a discount code, then apply that code at checkout.

Notes:
- Points are awarded on paid orders, so make sure the test order is marked as paid.
- The storefront widget requires the Online Store theme app block to be enabled.
```
